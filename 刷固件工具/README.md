# PrintSquare 刷固件工具

客户入口：

```text
一键刷入固件.bat
```

工具会自动完成：

- 提示安装 CH340/CH341 串口驱动
- 列出当前电脑检测到的 COM 串口
- 使用默认固件，或让用户手动选择其他 `.bin` 固件
- 询问是否先全擦 Flash（默认跳过，直接写入）
- 写入新的 ESP8266 固件

## 常见问题

如果没有检测到串口：

1. 在工具里选择安装 CH340/CH341 驱动。
2. 重新插拔 ESP USB。
3. 重新运行 `一键刷入固件.bat`。

如果烧录失败：

1. 关闭串口监视器、配置工具或其他占用 COM 口的软件。
2. 换一根支持数据传输的 USB 线。
3. 必要时按住 ESP 的 BOOT/FLASH 键再开始烧录。

默认刷入**不会**清空 ESP 里保存的 WiFi、Bambu token 和打印机选择（与 PlatformIO/DSH 推送固件的行为一致）。只有在刷入前手动输入 `E` 选择全擦 Flash 时才会清空，清空后需要重新打开后端配置工具完成配置。
