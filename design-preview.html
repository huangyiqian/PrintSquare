🎨 现代化改动说明

1. 环形进度条居中
SVG 渐变环形进度条为视觉中心，75% 大数字醒目，PROGRESS 标签轻量化。stroke-dasharray/stroke-dashoffset 实现。

2. 温度徽章环绕
喷嘴🔥、热床🛏️、仓温🌡️ 以小徽章形式分布在圆环周围，带 emoji 图标，比卡片更省空间更直观。

3. 毛玻璃半透明风格
所有元素用 rgba(255,255,255,0.03~0.08) + 1px border，比实色卡片更轻盈现代。

4. 背景径向渐变
从中心深蓝到边缘纯黑的径向渐变 radial-gradient，增加空间层次感。

5. 状态胶囊
顶部改为圆角胶囊标签，状态带发光绿点 box-shadow，更接近现代 UI 风格。

6. 层数信息嵌入
LAYER 42/168 以极小字放在环下方，不占独立卡片空间。

7. 底部统一
剩余时间和预计完成用横向半透明卡片，与整体毛玻璃风格一致。


⚡ 以上设计可用 TFT_eSPI 的 fillRoundRect + drawCircle + drawString + fillRect 分层逼近实现，不需要帧缓冲。渐变环可用分段弧线模拟。
