# 双打印机轮换固件（firmware-v0.5.40-rot）

本 fork 在 [huangyiqian/PrintSquare](https://github.com/huangyiqian/PrintSquare) 的 **V0.5.40** 基础上，
增加了一块 ESP8266 轮流显示两台拓竹打印机的功能。

- 固件版本号：`firmware-v0.5.40-rot`
- 预编译固件：`固件/printsquare-esp8266-rot-v0.5.40.bin`（575,024 字节）
- SHA-256：`6ADFC8D30ABFFB3F2A3EC8AEF0FD025A5BAA0BACA1246FE5683583B30F1D148C`
- 资源占用：RAM 62.6%（51,300 / 81,920 B）、Flash 54.7%（570,875 / 1,044,464 B）

## 实现方式

1. **一条 MQTT 连接订阅两台**
   - 连接后除 `device/<当前选中>/report` 外，再订阅 `device/<轮换搭档>/report`；
   - `get_version` / `pushing start` / `pushall` 分别发给两台；
   - 按 PUBLISH 的 topic 把遥测投递到两块内存状态：`pr`（当前显示）与 `prAlt`（后台更新）。
2. **定时轮换**
   - 到点直接交换 `pr` / `prAlt` 的整份数据并整屏重绘，不重连、不写 Flash；
   - 间隔 关闭 / 5 秒 / 10 秒 / 30 秒，存在 `/cloud.json` 的 `rotate_sec`，断电保存。
3. **8081 后台控件**
   - 「屏幕布局」卡片里新增「打印机轮换」分段按钮；`setRotate(v)` 通过 `POST /api/config` 写入。
4. **状态与配置接口**
   - `GET /api/status` 增加 `rotate_sec`、`rotate_active`、`rotate_partner`、`display_serial`；
   - `POST /api/config` 接受 `rotate_sec`（3~3600 秒，0 = 关闭），串口 JSON 配置同样支持。

## 使用步骤

1. 刷入固件（见下）。
2. 电脑端 `PrintSquare配置工具`：登录拓竹账号、写 WiFi，并**同步至少 2 台打印机**到 ESP。
3. 打开 `http://[ESP_IP]:8081/` → 「屏幕布局」→「打印机轮换」选 5 / 10 / 30 秒。
4. 屏幕每 N 秒在「当前选中的打印机」和「另一台」之间交替；选「关闭」固定回选中那台。

## 规则与限制

- 轮换对象 = 当前选中的打印机 ↔ 已同步列表里第一台不是它的打印机。想换搭档：在配置工具里对另一台点「显示这台并同步」。
- 当前实现最多轮换 2 台（列表里更多也只在前两台之间换），不做 N 台循环。
- 两台必须在同一个拓竹账号下（同一 token 才有订阅权限）。
- 每次切换会整屏重绘一次（百毫秒级），属正常现象，不会重新握手。
- 配置工具走 USB 串口写配置时使用 ASCII 编码，中文打印机名可能被写成 `??`；这是工具侧的历史问题，可用 HTTP 重新写入名称，或在 8081 里重设一次轮换开关刷新显示名。

## 刷入

```text
刷固件工具\一键刷入固件.bat
```

在「选择固件」步骤按 `C` 手动选择 `固件/printsquare-esp8266-rot-v0.5.40.bin`；
是否全擦按需选择（默认不擦除，保留 WiFi / Token / 打印机选择）。

platformio run -e sd2

- 串口日志确认两条订阅都成功：`Cloud MQTT subscribed: device/<A>/report`、`Cloud MQTT partner subscribed: device/<B>/report`

- 关闭轮换后固定显示选中那台；重新打开后恢复交替
- 8081 页面（80 与 8081 双端口）含轮换控件；`/api/status`、`/api/printers`、`/api/wifi/scan` 正常
- 3 分钟稳定性采样（每 5 秒）：轮换持续交替、两台数据均刷新、无请求失败，空闲堆 7.5–8.3 KB

## 尚未覆盖

- 未用拍照方式核对屏幕实际画面（亮度、切换瞬间、中文点阵）；
- 未做数小时长跑，也未覆盖「两台同时打印」的高数据量场景；
- 未做打印机断电/离线期间轮换显示的细节验证。

## 改动点（相对上游 src/main.cpp）

- `PrinterState` 增加 `statusReceived` / `lastActivity`；新增全局 `prAlt` / `rotatePartnerSerial` / `lastRotateSwapMs`
- 解析函数增加 `PrinterState &t` 目标参数，同一套解析服务两台
- `refreshRotatePartner()` / `rotationEnabled()` / `printerOptionModelFor()`
- `connectMqtt()` 双订阅、`publishMqttRequestTo()`、`requestPrinterState()` 两台都请求
- `mqttDispatchPublish()` 按 topic 路由（**topic 本体在 `mqttBuf+2`，前两字节是 topic 长度**）
- `loop()` 轮换定时器、两台独立离线判定、关闭轮换时切回选定机
- `applyConfigBody()` 支持 `rotate_sec` 并写回 `/cloud.json`
- 8081 页面：轮换控件、`setRotate()`、状态回显、i18n 词条
